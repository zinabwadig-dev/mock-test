# Mock Test: starter files

You will take this test **alone**, with your instructor watching your screen.

## Folder
Create one folder called `mock-test` and put everything inside it:

```
mock-test/
  part-1/   your HTML answers (you create the files)
  part-2/   index.html (given) + styles.css (you write)
  part-3/   part-3.js (you write)
  part-4/   index.html (given) + script.js (you write)
  part-5/   index.html + styles.css (given) + script.js (you write)
```

The starter folders already contain the given files. **Never edit a given `index.html` or `styles.css`** unless the question says so. You write only `styles.css` in part 2 and the `script.js` / `part-3.js` files.

## Tips
- Use the Console (F12) to see errors. Read the message before you change anything.
- Work in small steps and test each step.
- If you are stuck, say exactly where. It is fine to move on and come back.
